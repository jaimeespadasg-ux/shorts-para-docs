Privacy Policy – Shorts-para-docs

Last updated: 25 November 2026

Shorts-para-docs is a private, single-user tool developed and used only by its owner, the creator of the YouTube channels @jaime_docs and ClipsDocumentales. It uploads short vertical clips of the owner's own documentaries to the owner's own YouTube channel (ClipsDocumentales). It is not offered to the public and has no other users.

YouTube API Services

Shorts-para-docs uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies to the data handled through YouTube.

What data the app accesses

When the owner signs in with Google and grants access, the app requests these permissions:

  • youtube.upload – to upload videos to the owner's channel.
  • youtube – to read the authorised channel's ID and the status of the uploaded videos (to check that uploads go to the right channel and finished processing).

The app only uses the channel ID and title, and the status of videos it uploads itself. It does not read comments, subscribers, analytics, messages or any other personal data, and it does not access any other user's data.

How the data is used

The data is used only to upload the owner's own videos (title, description and video file, all created by the owner) and to confirm that each upload succeeded. It is not used for advertising, profiling, analytics, or any other purpose.

Storage and sharing

  • The Google authorisation token is stored only on the owner's own computer, in a local file. There are no servers, databases or third-party services involved.
  • No data is sold, shared with or transferred to anyone.
  • The app does not use cookies or tracking.

Retention, deletion and revoking access

The token is kept only while the tool is in use. Deleting the local token file removes all stored data. Access can be revoked at any time from the Google security settings page (Third-party apps with account access).

Limited Use

The use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Política de privacidad – Shorts-para-docs

Última actualización: 25 de noviembre de 2026

Shorts-para-docs es una herramienta privada de un solo usuario, creada y usada únicamente por su propietario, el creador de los canales de YouTube @jaime_docs y ClipsDocumentales. Sube clips verticales cortos de sus propios documentales a su propio canal (ClipsDocumentales). No se ofrece al público y no tiene más usuarios.

Servicios de la API de YouTube

Shorts-para-docs usa los Servicios de la API de YouTube. Al usarla se aceptan las Condiciones del servicio de YouTube, y a los datos tratados a través de YouTube se les aplica la Política de privacidad de Google.

Datos a los que accede

  • youtube.upload: subir vídeos al canal del propietario.
  • youtube: leer el ID del canal autorizado y el estado de los vídeos subidos, para comprobar que van al canal correcto y que se han procesado.

Solo usa el ID y el nombre del canal y el estado de los vídeos que ella misma sube. No lee comentarios, suscriptores, estadísticas, mensajes ni otros datos personales, ni datos de otros usuarios.

Uso de los datos

Solo para subir los vídeos del propietario (título, descripción y archivo, creados por él) y confirmar que la subida ha ido bien. Nunca para publicidad, perfiles, analítica ni ningún otro fin.

Almacenamiento y cesión

  • El token de autorización de Google se guarda solo en el ordenador del propietario, en un archivo local. No hay servidores, bases de datos ni servicios de terceros.
  • No se venden, ceden ni transfieren datos a nadie.
  • No usa cookies ni seguimiento.

Conservación, borrado y revocación

El token se conserva solo mientras se usa la herramienta; borrar el archivo local elimina todos los datos. El acceso se puede revocar en cualquier momento desde la página de seguridad de Google (Aplicaciones de terceros con acceso a tu cuenta).

Uso limitado

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de Uso limitado.
